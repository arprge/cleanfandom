# clean fandom

Fork of fandom focus

## What it does

- Removes the left explore bar, right rail (along with its collapse toggle), bottom toolbar, global footer, and "More Top Stories" feed.
- Collapses top and bottom ad containers so they don't leave blank gaps above the wiki header.
- Hides autoplaying Connatix and featured video players before they start floating in the corner.
- Dismisses OneTrust cookie banners and age-gate overlays while keeping page scrolling unlocked.
- Expands the main article column up to `1280px` wide without breaking VisualEditor or sticky tables of contents.

## Installation

1. Install [Violentmonkey](https://violentmonkey.github.io/) or [Tampermonkey](https://www.tampermonkey.net/)
